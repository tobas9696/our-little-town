Our Little Town website

index.html      the page (do not need to touch it)
residents.json  the list of residents. Add one line per new resident:

{
  "day": 2,
  "residents": [
    { "handle": "@firstperson", "number": 1, "day": 1 },
    { "handle": "@secondperson", "number": 2, "day": 2 }
  ]
}

number = house number (1 = Resident #1, the golden plot by the campfire).
